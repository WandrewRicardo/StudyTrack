# StudyTrack

Sistema de gerenciamento de atividades desenvolvido em Python utilizando Tkinter e SQLite.

## Funcionalidades

* Cadastro de atividades
* Listagem de atividades
* Atualização de status
* Armazenamento em banco de dados SQLite

## Tecnologias Utilizadas

* Python
* Tkinter
* SQLite

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de:

* Manipulação de banco de dados SQLite
* Desenvolvimento de interfaces gráficas com Tkinter
* Controle de versão com Git e GitHub

## Como executar

1. Clone o repositório

```bash
git clone https://github.com/WandrewRicardo/StudyTrack.git
```

2. Execute o arquivo principal

```bash
python main.py
```
